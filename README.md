# Anneler Günü Kartı 💗

Anne'ye özel, interaktif doğum günü/anneler günü kartı.

## Özellikler
- 💝 Animasyonlu kalp patlaması ile 200+ renkli konfeti
- 🌹 Premium cam fanus içinde açan gül animasyonu
- ✨ Parlayan yıldız ve neon parçacık efektleri
- 📱 Responsive tasarım - tüm cihazlarda çalışır
- 🎨 Modern glassmorphism design
- ⚡ Hiçbir external library gerektirmez (pure HTML/CSS/JS)

## Nasıl Kullanılır
1. `index.html` dosyasını browser'da aç
2. **"Kalbime Dokun ♥"** butonuna tıkla
3. Animasyonları izle 🎉
